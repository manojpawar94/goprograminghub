# Variables and Data Types

## Variables
```python
x = 5          # Integer
y = "Hello"    # String
z = 3.14       # Float
is_true = True # Boolean
```

## Basic Data Types
1. **Numbers**
   - Integers: `5`, `-3`, `0`
   - Floats: `3.14`, `-0.001`

2. **Strings**
   ```python
   name = "Alice"
   greeting = 'Hello World'
   ```

3. **Booleans**
   ```python
   is_active = True
   is_admin = False
   ```

## Type Checking
```python
type(5)        # <class 'int'>
type("Hello")  # <class 'str'>
type(True)     # <class 'bool'>
```

## Type Conversion
```python
int("5")      # 5
str(42)       # "42"
float("3.14") # 3.14
```
