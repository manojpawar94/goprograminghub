# Python Syntax Basics

## Indentation
Python uses indentation to define code blocks instead of curly braces.
```python
if 5 > 2:
    print("Five is greater than two!")
```

## Comments
```python
# This is a single-line comment

"""
This is a
multi-line comment
"""
```

## Variables
```python
x = 5       # Integer
y = "Hello" # String
```

## Print Function
```python
print("Hello World")
print(1, 2, 3, sep="-")  # Output: 1-2-3
```

## Multi-line Statements
```python
total = 1 + \
        2 + \
        3
```
